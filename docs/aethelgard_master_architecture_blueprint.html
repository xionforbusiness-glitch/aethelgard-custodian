03

The Battle of Bugs & Technical Triumphs

Real problems diagnosed, engineered solutions, and lessons learned across the journey
RESOLVED NTgCalls WebRTC
1. The 10ms Frame Sizing Mismatch
Symptom: Spoken audio played back at 2x chipmunk speed with stuttering and dropped packets.
Root Cause: The voice bridge defaulted to 20ms audio chunks (1920 bytes), whereas NTgCalls’ internal C++ WebRTC transport strictly expects 10ms frames (960 bytes at 48kHz mono).
Fix: Hardened `FRAME_MS = 10` and `TELEGRAM_FRAME_BYTES = 960`. Synchronized linear resampler pacing to 10ms intervals.
RESOLVED Acoustic Feedback
2. Acoustic Echo & Barge-in Loop
Symptom: Aethelgard cut himself off mid-sentence and reverted to: *"I'm listening, go ahead."*
Root Cause: Sound from the phone speaker leaked into the microphone (~200 RMS). Gemini Live’s Cloud VAD heard its own voice, interpreted it as user interruption, and purged the speech queue.
Fix: Implemented dynamic RMS gating in `feed_incoming_frame_48k`. When `ai_speaking` is active, mic audio < 520 RMS is dropped. User barge-in requires >200ms of loud voice.
RESOLVED google-genai SDK
3. Single-Turn Generator Expiry
Symptom: After the opening greeting, Aethelgard went completely deaf and ignored subsequent spoken orders.
Root Cause: In the `google-genai` SDK, `session.receive()` is an async generator scoped to a single turn. When `turn_complete` was reached, the generator terminated and the receiver worker died.
Fix: Wrapped `session.receive()` in a persistent `while self.is_connected and not self.is_closing:` loop, continuously reopening the generator for every dialogue turn.
RESOLVED Cloud Infrastructure
4. 1GB GCP Memory Thrashing
Symptom: Sudden SSH disconnects, system freezes, and systemd OOM-killer terminating the daemon.
Root Cause: Google Cloud Always Free Tier `e2-micro` instances provide only 1.0 GB of RAM. Running Chrome Playwright, Telegram WebRTC, and Python simultaneously saturated swap memory.
Fix: Provisioned high-performance Azure VM (Standard D4s v3 with 16 GB RAM and 4 vCPUs). Zero swap dependency and 100% stable headroom.
RESOLVED Async Telephony
5. Hangup Callback Exception
Symptom: Saying *"End the call"* triggered a `TypeError: NoneType cannot be used in await` and left the call hanging open.
Root Cause: `self.hangup_cb()` was invoked with `await` in `_hangup_after_delay`, but the registered callback was a synchronous function returning `None`.
Fix: Added runtime introspection (`if asyncio.iscoroutine(res): await res`). Added 3.0s audio buffer drain before sending `DiscardCallRequest`.
RESOLVED Conversational UX
6. Zero Dead Air Interleaving
Symptom: 1,500ms to 3,000ms of awkward silence while complex LLM reasoning and tools executed.
Root Cause: Traditional sequential pipelines wait for full model token generation and synthesis before playing any sound.
Fix: Dual innovation: Preliminary acoustic fillers (<70ms TTFV) for fallback mode, and Native Gemini 3.8 Live bidirectional streaming (~280ms) for primary voice mode.
